## Contrato público cerrado

Clase standalone `PurchaseIntentDialog`, selector `app-purchase-intent-dialog`.

Tipos en purchase-intent.types.ts:
```ts
export type PurchaseIntent = 'personal' | 'corporate' | 'resale' | 'new_idea';

export interface PurchaseIntentContext {
  readonly productId: string;
  readonly productName: string;
  readonly optionLabels: readonly string[];
  readonly isConcept: boolean;
}

export interface PurchaseIntentChoice {
  readonly intent: PurchaseIntent;
  readonly context: PurchaseIntentContext;
}
```

Métodos públicos:
- `open(context: PurchaseIntentContext, returnFocusTo?: HTMLElement): void`: capturar copia del contexto y destino de retorno (por defecto el elemento activo si es HTMLElement), mostrar diálogo y enfocar primera intención. Reabrir mientras está abierto actualiza contexto sin duplicar showModal ni lanzar error.
- `close(): void`: cancelación explícita e idempotente; cerrar, emitir cancelled una vez y devolver foco al destino si sigue conectado. No emitir si ya estaba cerrado.

Outputs Angular:
- `intentSelected = output<PurchaseIntentChoice>()`.
- `cancelled = output<void>()`.

Elegir una tarjeta emite una sola elección con copia del contexto capturado, cierra y restaura foco; no emite cancelled además. Una segunda interacción después del cierre no vuelve a emitir. Destruir el componente no produce una elección ni operación externa.

Estado solo en memoria dentro del componente. No servicios, almacenamiento local, router, autenticación, Firebase, navegación, cobros ni eventos de analítica. Ninguna intención concede permisos.

## Contenido e interacción

Título exacto: **¿Para qué lo quieres?**

Mostrar nombre del producto y opciones recibidas como resumen breve. Si isConcept, mostrar **Modelo en desarrollo · Su fabricación requiere evaluación.** Ningún precio ni promesa de disponibilidad.

| Valor | Título de tarjeta | Descripción |
| --- | --- | --- |
| personal | Para mí o para regalar | Elegir una o algunas piezas. |
| corporate | Para una empresa | Regalos corporativos y pedidos por cantidad. |
| resale | Para vender en mi tienda | Conocer la oferta y condiciones de reventa. |
| new_idea | Quiero desarrollar una idea | Explorar una pieza a partir de este producto. |

Usar cuatro botones nativos dentro de un dialog nativo. Título con aria-labelledby válido por instancia; cierre visible con nombre accesible Cerrar selección. Escape llama a cancelación, con un solo evento y restauración de foco. Click en backdrop no cierra en esta ficha. Enter/Espacio activan los botones por semántica nativa.

Sin seleccionar automáticamente una intención. No abrir cuatro modales ni un formulario posterior. El consumidor recibe el evento y decide el siguiente paso en otras tareas.

SCSS encapsulado: diálogo de ancho máximo 640px, limitado por viewport con margen; contenido con scroll si falta alto; dos columnas de tarjetas desde 640px y una por debajo. Usar base oscura #111512, texto #f8f4ea y acento #ff8a3c del contexto editorial, tipografía heredada y foco visible. No estilos globales, imágenes, iconos nuevos ni dependencias.

## Aceptación y pruebas

Usar TestBed/Vitest y un host de prueba que tenga un disparador enfocable. Simular únicamente métodos nativos del dialog si el entorno de tests no los implementa; no afirmar que eso prueba interacción real del navegador.

1. Abrir muestra título, producto, opciones y cuatro intenciones en orden; el original recibido no se modifica.
2. Cada tarjeta emite su valor exacto y el contexto que se abrió; no emite cancelación.
3. Botón de cierre y Escape cancelan sin elegir ni iniciar operación comercial; close repetido no duplica evento.
4. Cierre por elección/cancelación devuelve foco al disparador conectado. Si ya no existe, no lanza error.
5. Reabrir para otro producto sustituye el resumen y el contexto emitido; no conserva selección anterior.
6. Concepto muestra aviso de evaluación y no lenguaje de pago/disponibilidad confirmada.
7. Reapertura estando abierto no duplica diálogo/eventos; después de cerrar no hay doble emisión.
8. Revisar teclado, etiquetas, foco y estilos en código. No llamar a navegador salvo solicitud explícita.
